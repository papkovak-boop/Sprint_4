# Sprint_4

# Автотесты для веб-приложения «Самокат»

# Описание
Проект содержит автотесты для проверки работы выпадающих списков в разделе "Вопросы о важном", точки входа, работу кнопок заказа и формы оформления заказа на сайте «Самокат».  
Реализована параметризация тестов для разных браузеров (Chrome, Firefox) и для двух кнопок («верхняя» и «нижняя»).

# Стек
- Java 11
- Maven
- JUnit 4
- Selenium WebDriver
